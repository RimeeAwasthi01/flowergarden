# 🌸 FlowerGarden - Flower Delivery Website

A responsive flower delivery website built using **HTML, CSS, and JavaScript**.  
This project simulates a basic online flower ordering platform where users can explore services, view flower types, and submit contact forms.

##  Features

- Beautiful responsive homepage with hero section
- Services showcase using cards
- Flower types grid layout
- Contact form with validation (JavaScript)
- Interactive order button alert
- Multi-page structure (Home + About)
- Clean and modern UI design
- Google Fonts integration (Poppins)

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts
- Font Awesome Icons
